# HomePlate Health and Nutrition Logo Assets

Clean asset pack based on the selected concept: heart + home plate + leaf.

## Recommended files

| Use case | File |
|---|---|
| README header | `readme/homeplate-readme-banner.svg` |
| README header fallback | `readme/homeplate-readme-banner.png` |
| Main vector logo | `svg/homeplate-logo-stacked.svg` |
| Horizontal vector logo | `svg/homeplate-logo-horizontal.svg` |
| Icon/mark vector | `svg/homeplate-mark.svg` |
| Web favicon | `favicon/favicon.ico` |
| Apple touch icon | `favicon/apple-touch-icon.png` |
| iOS app icon set | `app/ios/AppIcon.appiconset/` |
| Android launcher icons | `app/android/mipmap-*/` |
| Expo icon | `app/expo/icon.png` |

## Markdown examples

```md
![HomePlate Health and Nutrition](readme/homeplate-readme-banner.svg)
```

## Colors

- Navy: `#0B1F3A`
- Green: `#3F8F3A`
- White: `#FFFFFF`

## Notes

- App icon PNGs are square and use a white background because iOS and many store contexts do not support transparent app icons.
- Logo PNGs and SVGs are transparent unless noted.
- Outlined SVG variants are included where available so the text keeps its shape even when the brand font is not installed.
